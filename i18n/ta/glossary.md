# Tamil translation guide for the Rewiring app

Audience: Tamil-speaking Christians in India and Sri Lanka, many of them not highly educated. Write in clear, warm, modern spoken-style written Tamil (பொதுத் தமிழ்), short sentences, everyday words. Avoid heavy Sanskrit or academic vocabulary when a common word exists. Use respectful "நீங்கள்" for the reader.

## Bible verses
- Quote verses in the style and wording of the Tamil Union Version (BSI, பழைய திருப்புதல் / Union Version) that Tamil churches use, as closely as you can. Use God = தேவன், LORD = கர்த்தர், Jesus = இயேசு, Christ = கிறிஸ்து, Holy Spirit = பரிசுத்த ஆவியானவர், Father (God) = பிதா.

## Format rules (the validator checks these)
- Keep every JSON key exactly as it is. Translate only the values.
- Some values are lists joined by ";" (a semicolon with NO space after it). Keep exactly the same number of ";" so the list items stay separate. A semicolon followed by a space is normal punctuation inside a sentence.
- Some values use ">" between steps of a loop, or "Reference|verse text" with a "|". Keep those separators exactly.
- HTML values: keep every tag, attribute, href, id and class exactly the same and in the same order. Translate only the visible text between tags. Do not add or remove tags.
- Keep quotation marks balanced; you may use Tamil-friendly quotes “ ” or plain quotes.
